# PHASE 0 — baseline, 01.11.2026

## Решение

**GATE: PASS для аудита baseline.** Есть актуальные QA, реальные кадры пяти стадий, установленное состояние веток и перечень непроверенного. Это не художественная приёмка, не разрешение на интеграцию и не PASS производительности Android. В capture-tool остаётся описанное ниже предупреждение при выходе.

Владелец уточнил цель: красивый мир, расслабление, простые механики, постепенное красивое усиление слизи; затем явно поручил работать с `main`. Рабочий промт и предложения: [RELAXATION_BRIEF.md](RELAXATION_BRIEF.md).

## Репозиторий и версии

- При старте: чистая `feature/glm-organic-visual-lab`, HEAD `66671b95eb5c4bfee5b3c7c4e0096b228aa3a515`.
- По прямому поручению владельца переключено на **main**, HEAD **`f21efb66b1b6413f4cec6b7afb289aef9ff16757`**. Пользовательского WIP до начала задачи не было. Собственная правка capture-tool перенесена; единственное изменение служебного timestamp памяти старой ветки отменено перед переключением.
- Локальный `main` содержит Claude V8 (`a783017`, `f21efb6`), которого нет в первоначальной GLM-ветке. Отчёты GLM/Claude считаются историческими, их результаты не заменяют нынешние проверки.
- Godot: `4.5.stable.official.876b29033`; desktop render: **Metal 3.2 / Forward Mobile / Apple M5**.
- Без fetch/pull, commit, push, merge, установки APK или публикации. Указанные remote refs — локально известное состояние, не свежая проверка сервера.

## Известные технические ограничения

- Захват S15 сохранил валидную пару, но при выходе выдал `ObjectDB instances leaked at exit` и **`2 resources still in use at exit`**. [Полный лог](../../reports/production/baseline/2026-11-01/main/smush-main-stage15.log). Причина не установлена; ресурсный teardown capture-tool требует отдельной диагностики. В source/PCK QA таких ошибок не обнаружено.
- Наличие готовых вариантов не означает согласованного художественного выбора. Claude остаётся лабораторным классом, GLM — экспериментальной опцией.
- Старый security-отчёт `docs/security/P0-next-16.4.3.md` зарегистрирован как историческое сообщение о web/Next.js. Его advisory IDs, актуальность и применимость сейчас не подтверждались; security scan в этой сессии **не выполнялся**. Патч не применялся. Это отдельный трек, а не заявление о безопасности.
- Доступность браузерного ChatGPT не проверялась: генерация новых изображений в PHASE 0 не потребовалась.

## Изменения и следующий шаг

Изменён только инструмент захвата: `SWAP_MODE` для съёмки существующего zen и метаданные seed/zoom/quality/mode/time в логе. Обновлены документы направления и проектная память. Основные игровые формулы, ассеты, шейдеры, сохранения и стандартный выбор стиля не изменены.

Откат: убрать локальный diff `tools/style_swap_capture.gd` и созданные документы/артефакты этой сессии, если они не нужны; не затрагивать существующие лаборатории и другие изменения владельца. Коммитов этой сессии нет.

Следующая фаза: PHASE 1 — конкретное художественное сравнение спокойного мира и слизи, затем выбор владельца согласно мастер-плану. Автоматического перехода к внедрению нет.
