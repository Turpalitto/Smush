# Slime Rush — браузерная версия

Играбельная версия из архива `slime-rush-game-development.zip`: Next.js, React,
Canvas2D и PostgreSQL. Основная Android-игра находится в корне репозитория
(`project.godot`). Правила объединения описаны в [INTEGRATION.md](../INTEGRATION.md).

## Запуск

Требуются Node.js 22+ и отдельная локальная база PostgreSQL.
Из корня репозитория:

```bash
cd web
npm ci
cp .env.example .env
# Укажите DATABASE_URL своей базы в .env
npm run db:push
npm run dev
```

Пример подключения в `.env.example` предназначен для локальной разработки.
`db:push` применяет схему к указанной базе; выбирайте базу для этой версии игры.
Откройте http://localhost:3000. `/api/health` проверяет доступ к PostgreSQL.

## Проверка

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

Для сборки нужен `DATABASE_URL` в окружении или `.env`. Запуск и API требуют
работающую БД с применённой схемой. Музыка по умолчанию выключена.

## Общее с Android-версией

Состав пяти синергий загружается напрямую из
[`resources/data/synergies.json`](../resources/data/synergies.json).
Адаптер в `src/lib/game/mutations.ts` переводит имена мутаций и сохраняет прежние
веб-ID (`electric`, `regen`, `storm_emp` и другие), поэтому это изменение не
сбрасывает существующие браузерные профили. Тесты проверяют соответствие всех
12 мутаций и активацию каждой синергии.

Сохранения двух платформ независимы: локальные файлы Godot и PostgreSQL-профили
браузера. Масштаб мира, баланс, экономика и уровни мутаций также остаются
платформенными: их прямое смешивание ломает темп игры и прогрессию.

Реклама и покупки в браузере используют **тестовые адаптеры**, реальные списания
не выполняются. Этот вариант предназначен для демонстрации и разработки,
перед коммерческим запуском нужны авторизация и серверная проверка покупок.

В [docs/](docs/) сохранена исходная документация архива как исторический материал.
Её утверждения об окружении и результатах проверок относятся к исходному проекту,
актуальные результаты объединения находятся в [INTEGRATION.md](../INTEGRATION.md).
