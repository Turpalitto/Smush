## Что исправлено в этой сессии

- Billing 3.3.0 возвращает `product_ids`, список `one_time_purchase_offer_details_list`
  и `token` в acknowledgement. Раньше код читал другие поля.
- Покупка выдаётся после успешного acknowledgement либо по уже подтверждённому
  store-ответу. Неизвестные SKU/пустые токены не выдаются; один токен может
  корректно разблокировать несколько товаров. Повторный restore восстанавливает
  локально потерянные права без создания новой выручки.
- Запоздалые успешные и неуспешные callbacks рекламы не меняют другой забег;
  параллельные запросы не перезаписывают ожидающую награду.
- Нельзя сначала забрать награду поражения, затем возродиться и получить её снова.
- Средняя сессия и длительность забега имеют отдельные счётчики. Частота побед
  над боссом считается по encounters. Ad opt-in и completion разделены.
  Новая установка не объявляется проваленным D7, неизвестная выручка — `null`.
- SDK и кэш GDScript не засоряют PCK/Android-пакет. Присутствует лицензия Godot
  и доступ к ней из раздела информации о приложении.

## Установленные инструменты и ограничения

Godot 4.6.3 (официальный Linux x86_64), Java runtime 21, Node 24.19.0.
Официальные Android export templates 4.6.3 скачаны и SHA512 проверена.
Gradle template распакован в игнорируемый `android/build/`.

Android SDK platform-tools/build-tools/platform 36 и полный JDK пока не
установлены. Автоматическое принятие лицензии SDK без ответа владельца
не выполнялось. Нет Android-устройства, keystore владельца и Play/AdMob аккаунтов.
Application ID `com.turpalitto.slimerush` — текущий кандидат, согласование владельцем
ещё требуется перед первым выпуском.

## Порядок возвращения к релизу — после отдельного решения владельца

1. Принять SDK terms владельцем; установить SDK и JDK по RELEASE_CHECKLIST.
2. Собрать `scripts/build_android.sh offline`, проверить подпись и установить APK.
3. Ручной полный забег, соотношения сторон, lifecycle, FPS, тепло и память на телефоне.
4. Настроить и проверить rewarded ads и покупки в официальных test tracks.
5. Согласовать ID, подготовить ключ, собрать AAB и пройти юридический/магазинный чеклист.
