# 2026-10-23 — environment art pass (commit 528cd72)

## What was built

- `tools/generate_floor_texture.py` — seamless 1024² moss floor tile, numpy + PIL only.
  Periodic by construction (wrapping value-noise lattice, modulo stamping). Measures its own
  seam: `0.0011` vs p99 interior step `0.0068` (ratio 0.19), exits non-zero if ratio > 1.
- `shaders/forest_canopy.gdshader` — UV → world pixels (floor scrolls under the camera), two
  samples of the same tile (1024 px and ×7) to kill the grid, luminance normalised against a
  baked mean (`FLOOR_TEXTURE_MEAN`) so it is a ±35% modulation, not a brightness shift.
  `floor_strength = 0` keeps the old gradient when the art is absent.
- `resources/art/props/*` — 5 FLUX props (root_pillar, rune_stone, mana_crystal,
  mushroom_cluster, fern_cluster) cut by the existing border flood fill, 256², mipmapped.
- `WorldGenerator` — `Sprite2D` per obstacle (width = radius × 2.45), pulsing halo behind
  crystals/monolith, squashed contact shadow, `_draw_prop_fallback()` if art missing; decor is
  weighted mushrooms 46% / moss 28% / fern 26%; arena edge = 3 staggered fern rows in its own
  `BorderHedge` node.
- `tools/quick_capture.gd` + `QuickCapture.tscn` — one frame of the real game in ~10 s
  (`QUICK_CAPTURE_STAGE=menu|arena`, `QUICK_CAPTURE_POS=x,y`, prints `App.state`).

## Bugs found (worth remembering)

1. **Inverted stamps.** `_smoothstep(e0, e1, x)` used `max(1e-6, e1-e0)` as the denominator, so
   with descending edges the mask flipped: every pebble/lichen dot stamped as a bright square
   with a hole. Looked like "digital camo" in-game. Fix: true `(x-e0)/(e1-e0)`.
2. **Texture scale.** A 1024 tile mapped to 420 world px = 2.4 texels per screen pixel → every
   detail aliased into squares. Set `floor_tile_px = 1024` (1:1) and made the fine detail
   coarser instead.
3. **Focus-loss pause.** The game auto-pauses on `NOTIFICATION_WM_WINDOW_FOCUS_OUT` (correct for
   mobile). Unattended captures and playthroughs froze mid-run. `quick_capture` reclaims focus
   and resumes; `GameManager` skips the auto-pause only when `PLAYTHROUGH_SUMMARY_PATH` is set.
4. `load()` inside `_draw()` per obstacle per frame → cached in `_prop_cache`.

## Floor relief + ray-traced AO (Blender pass, user offered "если что есть мсп блендер")

- The floor had a height field but only albedo was consumed. Added:
  - `tools/generate_floor_texture.py` now also writes `forest_floor_normal.png` (tangent-space,
    central differences through `np.roll` so the seam wraps) and a height map into
    `resources/art/environment/_source/` (a `.gdignore` folder — build input, never packed).
  - `tools/bake_floor_ao.py` — Blender 5.2.1 / Cycles. Height field becomes 9 tiled copies (3x3)
    so rays leaving the centre tile hit their own wrap-around neighbours; UV of the centre stays
    0..1, neighbours extrapolate outside. AO measured with the **Ambient Occlusion node** (explicit
    `Distance`) feeding emission, baked as EMIT — the built-in AO pass has no distance control.
    1.04M faces, 1024², 24 rays → 16 s on CPU. **Metal crashes the sandbox (exit 137)** → `--cpu`.
  - Shader takes `floor_normal` + `floor_ao`, each gated by its own uniform (`floor_relief`,
    `floor_occlusion`) so losing one map costs one layer only. Lambert is `dot(n,L)/L.z` so flat
    ground is exactly 1.0; AO is normalised on its own baked mean.
- **The real bug found on this pass was not the missing AO**: the tile measured 34 % relative
  contrast but *all* of it was in ~200 px patches, so at 1:1 the floor read as a smooth gradient.
  Added a high-frequency band (`clumps` ~20 px, `speck` ~10 px, `--grain 0.85`). Additive blending
  turned the tile into camouflage (it lifted dark soil as much as moss) → multiplicative with a
  bias below 1.0.
- Menu had to drop to `floor_strength 0.55` / `floor_tile_px 1400`: at full strength the grain
  competed with the title and buttons.
- AO/height alignment verified by correlation: 0.336 aligned vs 0.093/0.018/0.071 for v/u/both
  flips — so no UV flip is needed between Blender and Godot.
- QA **563 assertions, 0 failed**. Playthrough VICTORY 313.3 s, 64.9 HP, 85 absorptions, evo 5,
  178 essence. Post-limiter peak exactly −1.200 dBFS, 0 clipped, RMS −20.84 dBFS.
- `scripts/run_rendered_check.sh` refuses to start on macOS (it looks for WAYLAND_DISPLAY/DISPLAY

## Pass 3 — the world has no border (endless chunk streaming)

Request: "чтобы границы не было, чтобы всё было бесконечно и прекрасно".

- `WorldGenerator` rewritten: 512 px chunks streamed around the player (`STREAM_RADIUS` 3,
  `FREE_RADIUS` 5 for hysteresis, 7 chunks built per frame). `_chunk_content(cx, cy)` is a pure
  function of the chunk coordinate + world seed → walking away and back gives the identical
  forest (QA asserts the (0,0) prop signature survives a 4 km round trip).
- Removed: `border_rect` bands, `_build_border_hedge()`, `camera.limit_*`, and the hard clamp in
  `clamp_world_point()` (kept as a NaN/runaway guard so the ~10 call sites still work).
- Added aerial haze in the shader (`floor_fog`, `floor_fog_start/end`, `fog_tint`) using
  `(UV-0.5)*world_span` = distance from the player. Sprites can't be `mix`ed, so they get
  `modulate`→tint plus alpha→0 (`_apply_fog`), i.e. they dissolve instead of turning black.
- **The bug that mattered**: pools are the only bounded thing left, and nothing was recycling.
  Orbs (cap 85, one every 0.72 s) and enemies (cap 44) were never despawned, so a player who
  moved at all left orphans behind; the pool saturated and spawning near the player stopped.
  First endless playthrough: DEFEAT 303.6 s, 44 absorptions vs 261, 103 s with nothing to eat.
  Fix: `_cleanup_pools()` releases anything past the fog (1400 px) except miniboss/boss.
  The arena wall had been doing this for free.
- Undergrowth: FLUX set of 5 new ground-cover sprites (`tools/undergrowth_prompts.txt`,
  keyed with the new `--key-mode color`). The default flood fill keeps enclosed backdrop, which
  for a clump of leaves means magenta patches between the fronds. Also FLUX signed one render
  ("ZuctPank") in the corner — painted over with the measured backdrop median before keying.
- Decor now grows in thickets of one species (3–5 around a centre) plus 2–4 strays.
