# 2026-10-23 — environment art pass (commit 528cd72)

## What was built

- `tools/generate_floor_texture.py` — seamless 1024² moss floor tile, numpy + PIL only.
  Periodic by construction (wrapping value-noise lattice, modulo stamping). Measures its own
  seam: `0.0011` vs p99 interior step `0.0068` (ratio 0.19), exits non-zero if ratio > 1.
- `shaders/forest_canopy.gdshader` — UV → world pixels (floor scrolls under the camera), two
  samples of the same tile (1024 px and ×7) to kill the grid, luminance normalised against a
  baked mean (`FLOOR_TEXTURE_MEAN`) so it is a ±35% modulation, not a brightness shift.
  `floor_strength = 0` keeps the old gradient when the art is absent.
- `resources/art/props/*` — 5 FLUX props (root_pillar, rune_stone, mana_crystal,
  mushroom_cluster, fern_cluster) cut by the existing border flood fill, 256², mipmapped.
- `WorldGenerator` — `Sprite2D` per obstacle (width = radius × 2.45), pulsing halo behind
  crystals/monolith, squashed contact shadow, `_draw_prop_fallback()` if art missing; decor is
  weighted mushrooms 46% / moss 28% / fern 26%; arena edge = 3 staggered fern rows in its own
  `BorderHedge` node.
- `tools/quick_capture.gd` + `QuickCapture.tscn` — one frame of the real game in ~10 s
  (`QUICK_CAPTURE_STAGE=menu|arena`, `QUICK_CAPTURE_POS=x,y`, prints `App.state`).

## Bugs found (worth remembering)

1. **Inverted stamps.** `_smoothstep(e0, e1, x)` used `max(1e-6, e1-e0)` as the denominator, so
   with descending edges the mask flipped: every pebble/lichen dot stamped as a bright square
   with a hole. Looked like "digital camo" in-game. Fix: true `(x-e0)/(e1-e0)`.
2. **Texture scale.** A 1024 tile mapped to 420 world px = 2.4 texels per screen pixel → every
   detail aliased into squares. Set `floor_tile_px = 1024` (1:1) and made the fine detail
   coarser instead.
3. **Focus-loss pause.** The game auto-pauses on `NOTIFICATION_WM_WINDOW_FOCUS_OUT` (correct for
   mobile). Unattended captures and playthroughs froze mid-run. `quick_capture` reclaims focus
   and resumes; `GameManager` skips the auto-pause only when `PLAYTHROUGH_SUMMARY_PATH` is set.
4. `load()` inside `_draw()` per obstacle per frame → cached in `_prop_cache`.
