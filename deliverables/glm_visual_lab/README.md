# GLM organic visual lab — deliverables

- `shots/*.png` — сравнительные кадры (5 стадий × 2 стиля, мутации, мобильный
  размер). Закоммичены намеренно (исключение из `deliverables/*` через
  `git add -f`), чтобы ревью не зависело от локальной машины.
- `clips/*.avi` — видеодемонстрации движения и поглощения (6 с, 30 fps,
  ~14 МБ каждая). По политике репозитория `deliverables/*` не коммитятся и
  остаются локальными; пересоздаются командами из `docs/glm/04_TEST_RESULTS.md`
  (LAB_SHOT + `--write-movie`).
