# Объединение Godot и браузерной версии

Основной продукт — мобильная игра Godot из ветки `arena/6d0cda1c-smush`.
Браузерная версия сохранена как запускаемое приложение в `web/`.
Все 52 файла исходного ZIP представлены в истории и в дереве проекта:
код и тесты перенесены в `web/`, исходные документы — в `web/docs/`;
конфигурация Drizzle заменена на чтение `DATABASE_URL`.

## Решения

| Подсистема | Что использовано |
| --- | --- |
| Android, сцены, управление, шейдеры, SDK | Существующий Godot-проект в корне |
| Браузерная игра | Canvas2D/React/Next.js из ZIP, в `web/` |
| Синергии | Единственный источник рецептов: `resources/data/synergies.json`; веб-адаптер переводит старые ID |
| Сохранения Godot | Существующие checksum и резервная копия + проверка полей по подходу `sanitizeProfile` из ZIP; запись через временный файл и переименование |
| Браузерные профили | PostgreSQL; дополнительно исправлены нечисловые/бесконечные значения и недопустимые уровни улучшений |
| Баланс и экономика | Сохранены для каждой платформы: разные масштабы мира, уровни, лимиты массы и цены нельзя подменять без перебалансировки |
| Документация | Основная документация Godot сохранена; оригиналы из ZIP хранятся в `web/docs/` |
| Проверки | Godot QA из исходников и PCK; отдельные тесты, типизация, lint и сборка браузера |

### Совместимость идентификаторов

| Godot | Браузер |
| --- | --- |
| `speed_boost` | `haste` |
| `regeneration` | `regen` |
| `ranged_absorb` | `vacuum` |
| `electro_discharge` | `electric` |
| `mimicry` | `camouflage` |
| синергия `em_storm` | `storm_emp` |

Остальные ID мутаций/синергий совпадают. Существующие ID браузера не переименованы.
Профили платформ автоматически не объединяются: валюты, покупки и прогресс
хранятся в разных форматах и имеют разную экономику.

### Восстановление сохранений

Godot теперь проверяет вложенные контейнеры и типы даже у JSON с верной
контрольной суммой: исправляет отрицательные счётчики, неверные настройки,
повреждённые уровни улучшений, неизвестные ID и недоступные выбранные формы.
Корректные значения сохраняются, стартовые мутации восстанавливаются.
Резервная копия предыдущего сохранения сохраняет прежнее поведение.
